# Done specs

Specs whose done-conditions have been met and whose feature shipped. Kept for
the decision record — what was built, why, and what the open follow-ups were at
sign-off.

`docs/specs/` (the parent dir) holds only **active work** (`ready` / `draft` /
`in-progress`). When a spec flips to `done` or `shipped`, it moves here. The
1:1 feature catalog entry (`docs/features/<slug>.md`) is the source of truth
for "what does it do today"; the spec here is the *why and how it was decided*.
