Interaction model · three bets

How should ActionAmp feel to move through?

The visual DNA is fixed (Things + teal/amber). The question now is the interaction model — how you switch lens, start tasks, move between modes, review. Three genuinely different approaches. Each is a clickable prototype. Open all three, then tell me which one feels like home.

A · Spatial
Zoom + Pan
Task → Project → Goal is zoom (Figma for your work). Past → present → future is pan. No sidebar — movement is the navigation.
