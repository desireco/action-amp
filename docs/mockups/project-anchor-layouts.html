Con: it's a list — the exact thing ActionAmp demotes elsewhere. Risks feeling like "just another task manager project view."

Layout 2 — Action-forward. The Project frames the top (name + progress + goal as a compact header), then the next action is the hero — same DNA as What Now (circle, title, Do this / Switch). Other tasks are quiet chips. Pro: consistent with the whole app's thesis — arriving somewhere still points you at one thing to do. Con: hides the task list; reviewing all tasks needs a second step.

My lean: Layout 2. It keeps the "What Now" DNA even inside a Project — you arrived at the project, and it immediately tells you what to do there. Layout 1 is the safe choice but it's the list view we're trying to demote. But Layout 2 needs an obvious "see all tasks →" affordance so the list is one tap away.
