Add to ActionAmp

A bookmarks-bar button that captures the page you're reading — title, URL, and any text you have selected — and opens it in ActionAmp's share review, the same confirm flow your phone's share sheet uses. Nothing is captured until you confirm there.

Add to ActionAmpproduction — drag me to the bookmarks bar Add to ActionAmp (dev)localhost:5174 — for local testing
  1. Show your bookmarks bar (Ctrl+Shift+B in Chrome and Firefox).
  2. Drag the button above onto the bar.
  3. On any page, click it. ActionAmp opens in a new tab with the capture prefilled — add a note, pick a destination, confirm.
Can't drag? Paste it instead

Create a bookmark manually (right-click the bookmarks bar → Add page), name it Add to ActionAmp, and paste this as the URL:

javascript:(function(){var p=new URLSearchParams();p.set('title',document.title.trim().slice(0,2000));p.set('url',location.href);var s=String(getSelection()).trim();if(s)p.set('text',s.slice(0,2000));window.open('https://app.actionamp.com/share?'+p)})();

Be logged in to ActionAmp in the same browser first — the review page needs your session to confirm. The readable source lives at bookmarklet/actionamp-share.src.js in the repo.
