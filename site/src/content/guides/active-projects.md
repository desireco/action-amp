There is no magic number. The useful limit is the number of projects that can each receive a real next action this week. Naming ten projects “active” does not create time for ten projects.

For most people, that is fewer than the number they have named. Try this:

- Pick one or two projects that must move now.
- Keep a small number of maintenance projects visible.
- Move every other legitimate project to later, with a review date.

“Later” is not abandonment. It is an honest statement that a project cannot receive attention today.

If every project stays active, none has a clear claim on your time. Limiting active work is how you make finishing possible.
